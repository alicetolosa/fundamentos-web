>🧱 Estrutura básica do HTML
- <!DOCTYPE html> → define o tipo de documento
- <html> → raiz da página
- <head> → configurações e metadados (parte não visível)
- <body> → conteúdo visível da página

>⚙️ Meta Tags
- charset="UTF-8" → suporte a acentos
- viewport → responsividade
- description → SEO

>🔗 Links
- Uso da tag a
- Atributo target="_blank" → abre em nova aba
Boas práticas com rel="noopener noreferrer"

>🖼️ Imagens
- img → exibir imagens
- alt → acessibilidade e SEO
- width → controle de tamanho

>📊 Tabelas
- table → estrutura da tabela
- tr> → linhas
- th> → cabeçalho
- td> → dados
📌 Exemplo prático: tabela de produtos

> 📝 Formulários
- label → descrição do campo
- for → conexão com input
- input → entrada de dados
- type="text" → campo de texto
- button type="submit" → envio do formulário

**🧩 Boas práticas aprendidas**
Uso correto de label para acessibilidade, evitar br para layout (preferir CSS), separação entre estrutura (HTML) e estilo (CSS) e uso semântico das tags.
