# Comandos Git

## Adicionar os arquivos pela 1º vez:

- git init  
- git add .
- git commit -m "feat: projeto inicial"
- git remote add origin https://github.com/seu-usuario/nome-do-repo.git
- git branch -M main 
- git push -u origin main
